# REFURBICON Client

React + Vite frontend for REFURBICON — admin ERP, customer shop (`/shop`), and mobile face attendance (`/m`).

## Setup

```bash
npm install
npm run dev
```

App runs at http://localhost:5173 (API proxied to http://localhost:5000).
